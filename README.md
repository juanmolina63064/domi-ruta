# DomiRuta Manizales

Sistema de gestión de domicilios en Python para el curso Estructuras de Datos Aplicadas (230G8F).

El proyecto se organiza en tres fases:

1. Nodos, listas enlazadas y recursión.
2. Pilas, colas, cola de prioridad y tabla hash.
3. Árbol binario de búsqueda y reportes ordenados.

## Ejecución

Desde la carpeta del proyecto:

```bash
python main.py
```

Pruebas automatizadas:

```bash
python pruebas.py
```

Experimento de rendimiento:

```bash
python experimento.py
```

Consulta el PDF de instrucciones del curso para las reglas completas de entrega y sustentación.

> El código fuente completo y su documentación deben incorporarse al repositorio desde el paquete de entrega generado para el proyecto.
